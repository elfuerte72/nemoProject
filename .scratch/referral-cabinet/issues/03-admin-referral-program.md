# Панель: подраздел «Рефералка», карточка клиента, сводка на N линий

Status: done
Этап: 3
Blocked by: 01

Настройки, подраздел `/settings/referral` (строка в `SETTINGS_SECTIONS`,
страница через `SettingsSection`): линии — список с процентом каждой,
добавить/убрать (глубина 1..5); уровни — таблица: название, порог по
активным рефералам, проценты по линиям, добавить/удалить; минимальная
сумма вывода переезжает сюда из «Экономики» (там остаётся наценка,
минимум обмена, срок). Маршруты `PUT /api/referral-program/lines`,
`POST/DELETE /api/referral-program/tiers/[id]`; bps ↔ % через
`lib/percent.ts`. Подсказка «как устроено»: старшинство ставок, что
такое активный реферал, что прошлое не пересчитывается.

Карточка клиента (`client-card.tsx`, `lib/client-card.ts`): «Привёл
клиентов» списком по линиям до глубины; уровень; личные ставки —
администратору форма по линиям с «сбросить»; коды клиента с видом и
названием; «Правка баллов» — раскрытием строки, как у отказа мерчанту:
сумма со знаком и комментарий, кнопка не гаснет. Маршруты
`PUT /api/clients/[id]/referral-rates`, `POST /api/clients/[id]/bonus-adjustment`.
Менеджер видит без кнопок.

Раздел «Рефералка»: плитки «начислено» на N линий (без жёсткой
деструктуризации двух), плитка «уровней». Уведомления и справка
консьержа — из тикета 01, здесь проверить глазами тексты.

Тесты: маршруты — форма тела и коды отказов; `bot-slop` на подсказку.
Вёрстка глазами: подраздел, карточка клиента с формой ставок, правка
баллов.
