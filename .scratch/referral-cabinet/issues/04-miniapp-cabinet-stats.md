# Mini App: уровень и ставки, статистика по периодам, список рефералов

Status: done
Этап: 4
Blocked by: 02

`profile-section.tsx` растёт в кабинет (спека, «Mini App»). Верх как
был: баланс, «заработано всего», «Вывод», «Пригласить». Дальше:

- **Уровень и ставки**: имя уровня, ставки по линиям с источником
  словами, полоса до следующего уровня (`.progress`, новая поверхность
  в `globals.css`); без уровней — ставки списком. Плашка `.split` на
  две линии уходит.
- **Статистика**: ряд `.filters` — сегодня, 7, 30, 90 дней (свой отрезок
  не нужен: экран телефона); плитки «пришли», «стали активными»,
  «начислено», «выплачено» с сравнением с прошлым периодом (стрелка и
  разница готовым числом с сервера); столбики по дням за две недели —
  `.bars` разметкой на CSS, высота из числа; оборот приведённых строкой
  по валютам. Период — свой запрос `GET /api/referral-stats` при смене
  фильтра, смещение пояса из браузера.
- **Рефералы**: первые пять строк и кнопка «Все» — лист со списком и
  «Показать ещё» по смещению (см. тикет 02: курсор нёс бы идентификатор). Строка: дата, линия, откуда пришёл
  (название ссылки или промокод), активен, заявок, принёс, последний
  обмен.

Загрузка и отказ — как у раздела сейчас (`Loading`, `Failure`,
частичный отказ строкой `.error`); статистика не блокирует остальное.
Правило перечитывания по счётчику возвращений сохраняется.

Тесты: `lib/referral-stats-view.ts` — сравнение периодов словами и
знаком, высота столбика из чисел (закрепить: пустой день — ноль, а не
NaN); `bot-slop` на новые подписи. Вёрстка глазами через Playwright с
initData локально: нет горизонтальной прокрутки, цель нажатия фильтра
под палец.
