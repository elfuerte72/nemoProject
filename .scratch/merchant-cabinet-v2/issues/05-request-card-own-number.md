# Карточка заявки: свой номер в шапке, наш — рядом

Status: ready-for-agent
Раздел: Заявки

Заголовок карточки — «Заявка 6043e1f3», обрезок нашего идентификатора.
Номер самого мерчанта, `order-1011`, стоит мелко в подзаголовке. Должно
быть наоборот: мерчант ищет заявку по тому номеру, который знает его
система и его клиент, — «бронь 1024», «заказ 1013». Нашего номера он не
видел нигде, кроме этой страницы.

## Что сделать

- Свой номер (`reference`) — заголовком страницы. Нет своего номера —
  заголовком остаётся наш, как сейчас: у заявки, заведённой менеджером,
  его может не быть.
- Наш идентификатор — целиком, а не восемью знаками, рядом с кнопкой
  копирования: по нему заявку называют в поддержке и по нему же ходит
  API (`GET /api/v1/requests/{id}`). Обрезок скопировать можно, а найти
  по нему нельзя. Кнопка — готовая деталь `copy` из `@nemo/ui`.
- Длинный идентификатор на узком экране переносится по любому знаку —
  правило про неразрывные строки уже записано в `CLAUDE.md`.

## Чего здесь не будет

Правки своего номера из кабинета: его назвала интеграция, и заявка с
номером, который разошёлся с системой мерчанта, хуже заявки без него.
