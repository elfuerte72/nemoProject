# Разведка: котировки P2P на рублёвую сторону

Status: ready-for-human

**Остановлено 12 августа 2026** по решению Пенкина: делаем баты и юани
по ТЗ, P2P не трогаем. Запись заведена в `backlog.md`. Рублёвую сторону
продолжает котировать Rapira.

Владелец просит тянуть курсы с Bybit P2P — с фильтрами по проверенным
мерчантам, «как торгует агент». Костя обещал прислать API по рублям от
банка.

## Что известно

Публичного API под P2P-котировки у Bybit не опубликовано: в каталоге
public-apis Bybit значится только биржевым API с ключом, и это про
деривативы. Котировки объявлений живут во внутреннем адресе сайта — тем,
что использует сама страница. Обращаться к нему можно, но это не
договор: адрес меняется без предупреждения, ответ отдаётся с защитой от
роботов, а частые обращения с серверного адреса блокируются.

Прецедент из того же каталога: `paralelo.bo` отдаёт параллельный курс
доллара в Боливии, собранный из P2P-источников раз в минуту. То есть
задача решаемая, но решается она отдельным сборщиком, а не «одной
строкой в цепочке».

## Что сделать до обещаний

Разведка на день, с ответом в этот файл:

- отвечает ли внутренний адрес Bybit с серверного адреса нашего
  деплоя, и как долго держится без блокировки;
- какие фильтры доступны (проверенные мерчанты, способ оплаты, объём) и
  как из ленты объявлений получается одно число — медиана, лучшая цена,
  средняя по первым N;
- чем это отличается от нынешней цены Rapira на тех же объёмах;
- что даёт API от Кости, когда он придёт: если банк отдаёт курс
  договором, он лучше парсинга по определению.

## Почему не сразу в работу

Курс — это цена, по которой сервис обязуется работать. Источник,
который может замолчать без предупреждения и без договора, ставить
первым в цепочку нельзя, а вторым он мало что добавляет. Решение —
за владельцем, после разведки.
