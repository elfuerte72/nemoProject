# Резервный источник фиатных курсов

Status: ready-for-agent

Из разбора каталога public-apis, 11 августа 2026. Владелец в тот же день
разрешил менять источники при условии, что курс по-прежнему считается из
памяти, а не запросом наружу в ответ клиенту. Закрывает записи
бэклога «Rapira ненадёжна, а источник курса у сервиса один» и половину
«Курс ЕЦБ не обновляется по выходным».

## Что нашлось

- **`exchangerate.dev`** — совместим по формату с Frankfurter, которым
  сервис пользуется сейчас: подменяется адресом, разбор ответа тот же.
  10 тысяч запросов в месяц без ключа. Самый дешёвый резерв из
  возможных.
- **`currency-api` (fawazahmed0)** — без ключа и без лимитов, 150+
  валют, отдаётся с GitHub. Формат свой, разбор придётся написать.
- **ЦБ РФ** — официальный курс рубля без ключа. Для сделки не годится
  (по официальному курсу никто не торгует), но годится для сверки: если
  наш курс разошёлся с официальным на десятки процентов, что-то сломано.

## Что сделать

Второй фиатный источник в цепочку после ЕЦБ. Порядок значим: первым
отвечает тот, чью цену сервис считает своей.

Оговорка про выходные остаётся: у резервного источника те же опорные
курсы, и в воскресенье он назовёт пятничную цену. Дыру закрывает не
резерв, а рыночный источник — для бата это Bitkub из тикета 01.

## Чем доказывается

- Фикстура ответа резервного провайдера, записанная с живого запроса.
- Тест: молчание первого источника отдаёт курс второго, а не пустоту.
- Тест: пока первый отвечает, второго не спрашивают вовсе.
