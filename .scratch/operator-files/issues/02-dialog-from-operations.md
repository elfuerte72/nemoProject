# 02. Переход в переписку из каждой операции

Status: done

## Сделано

- Заявка на обмен: «Написать клиенту» в заголовке карточки, рядом с
  пилюлей состояния; ведёт в переписку с подставленным номером заявки.
  Кнопка в карточке клиента осталась — тем же устройством, что у
  страницы клиента.
- Очередь выплат: «Написать» первой кнопкой в столбце «Что сделать».
- Заявки на карту: то же; столбец переименован из «Перевести в» в «Что
  сделать» — в нём теперь не только переходы.

## Проверено

Глазами на своей машине: кнопка стоит в каждом из трёх мест, строка не
разъезжается, горизонтальной прокрутки на узком экране нет.
