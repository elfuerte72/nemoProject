# Снимок обновляется сам, пока процесс жив

Status: ready-for-human

Сегодня кэш освежается только визитом клиента: `warmUp()` отрабатывает
один раз при запуске, дальше обновление уходит из `current()` — то есть
тогда, когда кто-то уже спросил. При трёх заявках за две недели пауза
между клиентами измеряется часами, и снимок мёртв к приходу каждого.

Нужен таймер: пока процесс жив, снимок обновляется с периодом `ttlMs` и
не доживает до потолка.

- Acceptance:
  - таймер заводится там же, где прогрев, и один раз — второй вызов своей
    череды не заводит;
  - период равен `ttlMs`;
  - таймер `unref()` — процесс он не держит;
  - отказ провайдера таймер не роняет: пишется в журнал, следующий круг
    идёт как обычно.
- Verify: `cd packages/rates && pnpm run test` — тесты на подменных
  таймерах (`vi.useFakeTimers()`).
- Files: `packages/rates/src/snapshots.ts`,
  `packages/rates/src/snapshots.test.ts`.
