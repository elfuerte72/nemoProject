# 10 — Реферальные начисления при исполнении заявки

**What to build:** в момент, когда заявка становится исполненной, обе линии рефереров получают баллы — процент от дохода сервиса по этой сделке. Это единственная точка начисления во всей системе.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Исполнение заявки начисляет баллы рефереру первой линии по ставке из настроек
- [ ] Если у реферера есть свой реферер, начисление получает и вторая линия по своей ставке
- [ ] База начисления — доход по заявке, а не её сумма
- [ ] Повторный вызов исполнения не создаёт второго начисления; защита обеспечена ограничением базы, а не проверкой в коде
- [ ] Исполнение заявки клиента без реферера начислений не создаёт
- [ ] Начисление и смена статуса выполняются в одной транзакции: откат одного откатывает другое
- [ ] Реферер получает уведомление о начислении
