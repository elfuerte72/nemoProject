# 13 — Заявка на европейскую карту

**What to build:** клиент оставляет заявку на открытие карты и видит, как она движется. Сервис карту не выпускает — менеджер ведёт статус по данным внешнего провайдера.

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] Клиент подаёт заявку на открытие европейской карты
- [ ] Менеджер ведёт статус: подана, в обработке, активна, отклонена
- [ ] Клиент видит текущий статус и получает уведомление о каждой смене
- [ ] Повторная заявка при уже активной карте не создаётся
- [ ] Система не выпускает карту, не хранит её данные и не проводит по ней операций
