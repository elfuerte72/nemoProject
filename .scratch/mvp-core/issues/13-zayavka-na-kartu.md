# 13 — Заявка на европейскую карту

**What to build:** клиент оставляет заявку на открытие карты и видит, как она движется. Сервис карту не выпускает — менеджер ведёт статус по данным внешнего провайдера.

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [x] Клиент подаёт заявку на открытие европейской карты
- [x] Менеджер ведёт статус: подана, в обработке, активна, отклонена
- [x] Клиент видит текущий статус и получает уведомление о каждой смене
- [x] Повторная заявка при уже активной карте не создаётся
- [x] Система не выпускает карту, не хранит её данные и не проводит по ней операций

## Comments

Повторная заявка не создаётся не только при активной карте, но и пока
предыдущая в работе. Тикет говорит про активную, но случай тот же:
провайдер получил бы два обращения об одном человеке, а клиент — два
разных статуса на один вопрос «где моя карта». После отказа заявка
подаётся заново.

Переходы вынесены таблицей в `@nemo/types` рядом с переходами заявки на
обмен: экран менеджера строит кнопки из неё же, поэтому своя копия
правил на экране разойтись с ядром не может.

Сверх тикета: менеджер может записать номер заявки у провайдера
(`provider_reference`). Колонка в схеме уже была и пустовала, а сверяться
с провайдером по чему-то нужно. Данных карты это не касается — их сервис
не хранит.
