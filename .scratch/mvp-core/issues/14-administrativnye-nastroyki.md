# 14 — Административные настройки

**What to build:** администратор управляет сотрудниками и экономикой сервиса — наценками по направлениям, ставками реферальных линий и минимальной суммой вывода — не трогая код.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] Администратор добавляет сотрудника, назначает ему роль и отключает доступ
- [ ] Менеджер не имеет доступа к разделу настроек
- [ ] Администратор настраивает наценку по каждому валютному направлению
- [ ] Администратор настраивает ставки первой и второй линии
- [ ] Администратор задаёт минимальную сумму вывода
- [ ] Изменение ставок не пересчитывает уже сделанные начисления — прошлые сделки остаются с теми условиями, при которых были исполнены
- [ ] Изменения настроек записываются с указанием, кто и когда их внёс
