# 02 — Каркас операций и регистрация клиента с реферальной привязкой

**What to build:** человек открывает приложение из бота и становится клиентом без всякой регистрации. Если он пришёл по реферальной ссылке — закрепляется за пригласившим, а тот сразу получает уведомление. Появляется модуль прикладных операций, через который отныне проходят все изменения состояния.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] Появился модуль операций; ни одно приложение не обращается к базе напрямую
- [x] Первый запуск Mini App создаёт клиента по подписанным данным запуска; повторный запуск дубля не создаёт
- [x] Запуск по реферальной ссылке создаёт связь первой линии, а если у реферера сам есть реферер — то и связь второй
- [x] Реферер получает уведомление о регистрации реферала; реферер второй линии — уведомление о новом партнёре
- [x] Привязка неизменяема: повторный запуск по чужой ссылке реферера не меняет
- [x] Попытка привязать клиента к самому себе отвергается
- [x] Данные запуска с подделанным идентификатором клиента отвергаются, клиент не создаётся
