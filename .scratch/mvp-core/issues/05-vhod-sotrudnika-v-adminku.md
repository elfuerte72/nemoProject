# 05 — Вход сотрудника в админ-панель

**What to build:** менеджер входит в админку через Telegram, без отдельного пароля, но с обязательным вторым фактором. Доступ получают только те, кто заведён в списке сотрудников.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Вход выполняется через Telegram Login, подпись проверяется
- [ ] Допуск получают только сотрудники из списка; остальные получают отказ без подсказок о том, что именно не так
- [ ] Второй фактор обязателен: без подтверждения кодом сессия не выдаётся
- [ ] Отключённый сотрудник теряет доступ немедленно, не дожидаясь истечения сессии
- [ ] Сессия истекает по времени и требует повторного входа
- [ ] Подпись, сделанная по схеме Mini App, для входа в админку не принимается — схемы подписи у клиентской и служебной частей разные
