# 16 — Согласие на рассылку и ручные рассылки

**What to build:** при первом входе клиент решает, присылать ли ему предложения, и может отписаться в любой момент одной кнопкой. Администратор отправляет рассылку из админки — только тем, кто согласился.

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] При первом входе клиент отвечает на вопрос о согласии на рассылку
- [ ] Клиент отписывается одной кнопкой; согласие снимается немедленно
- [ ] Администратор составляет и отправляет рассылку из админки
- [ ] Сообщения уходят только клиентам с действующим согласием
- [ ] Отправка учитывает ограничения Telegram на частоту и не роняет бота на большом списке
- [ ] Клиенты, заблокировавшие бота, не ломают рассылку остальным
- [ ] Администратор видит результат отправки: сколько доставлено, сколько не удалось
