# 07 — Завершение сделки с фиксацией дохода

**What to build:** менеджер отмечает поступление оплаты, отправляет деньги клиенту и закрывает заявку, указав, сколько сервис на ней заработал. Этот доход — база всех реферальных начислений, поэтому без него завершить сделку нельзя.

**Blocked by:** 06

**Status:** ready-for-agent

- [x] Менеджер отмечает поступление оплаты — заявка переходит в «оплата получена»
- [x] Менеджер завершает сделку, указывая доход по заявке — заявка переходит в «исполнена»
- [x] Завершение без указания дохода отвергается
- [x] Доход сохраняется без потери точности и с указанием валюты
- [x] Клиент получает уведомление о завершении сделки
- [x] Исполненная заявка не допускает дальнейших переходов
