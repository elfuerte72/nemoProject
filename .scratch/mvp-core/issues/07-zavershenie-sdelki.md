# 07 — Завершение сделки с фиксацией дохода

**What to build:** менеджер отмечает поступление оплаты, отправляет деньги клиенту и закрывает заявку, указав, сколько сервис на ней заработал. Этот доход — база всех реферальных начислений, поэтому без него завершить сделку нельзя.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Менеджер отмечает поступление оплаты — заявка переходит в «оплата получена»
- [ ] Менеджер завершает сделку, указывая доход по заявке — заявка переходит в «исполнена»
- [ ] Завершение без указания дохода отвергается
- [ ] Доход сохраняется без потери точности и с указанием валюты
- [ ] Клиент получает уведомление о завершении сделки
- [ ] Исполненная заявка не допускает дальнейших переходов
