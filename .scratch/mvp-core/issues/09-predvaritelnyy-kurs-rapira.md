# 09 — Предварительный курс для электронных переводов

**What to build:** клиент, выбравший электронный перевод, ещё до подачи заявки видит встречную сумму — котировку внешнего источника с наценкой направления. Курс помечен как предварительный: он справочный, финальный называет менеджер.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Источник котировок скрыт за одним интерфейсом «дай котировку по паре»; Rapira — одна из его реализаций, а не вшитая зависимость
- [ ] Для электронного перевода клиент видит встречную сумму, пересчитанную по котировке с наценкой направления
- [ ] Курс сопровождается явной пометкой, что он предварительный и финальный подтвердит менеджер
- [ ] Для наличных котировка не запрашивается — там ставку называет менеджер
- [ ] Недоступность провайдера не мешает подать заявку: экран сообщает, что курс назовёт менеджер
- [ ] Котировка кэшируется на короткое время, чтобы ввод каждой цифры не порождал запрос к чужому API
- [ ] Наценка берётся из настроек направления, а не из кода
