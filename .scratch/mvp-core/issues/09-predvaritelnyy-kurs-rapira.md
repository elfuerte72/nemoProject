# 09 — Предварительный курс для электронных переводов

**What to build:** клиент, выбравший электронный перевод, ещё до подачи заявки видит встречную сумму — котировку внешнего источника с наценкой направления. Курс помечен как предварительный: он справочный, финальный называет менеджер.

**Blocked by:** 03

**Status:** ready-for-agent

- [x] Источник котировок скрыт за одним интерфейсом «дай котировку по паре»; Rapira — одна из его реализаций, а не вшитая зависимость
- [x] Для электронного перевода клиент видит встречную сумму, пересчитанную по котировке с наценкой направления
- [x] Курс сопровождается явной пометкой, что он предварительный и финальный подтвердит менеджер
- [x] Для наличных котировка не запрашивается — там ставку называет менеджер
- [x] Недоступность провайдера не мешает подать заявку: экран сообщает, что курс назовёт менеджер
- [x] Котировка кэшируется на короткое время, чтобы ввод каждой цифры не порождал запрос к чужому API
- [x] Наценка берётся из настроек направления, а не из кода

## Comments

Реализация Rapira вынесена в отдельный пакет `@nemo/rates`, а не в
`@nemo/core`: ядро в сеть не ходит, а провайдеров по блокеру C1 будет
несколько. Интерфейс `RateSource` объявлен в ядре, реализация
подключается в `apps/miniapp/lib/core.ts` — так заявка на обмен не знает,
у кого спрошена цена.

`RAPIRA_KEY` необязателен: публичный список котировок отдаётся без него,
и отсутствие ключа не мешает развернуться. Если задан — уходит в
заголовке.

Котировки приходят числами JSON, то есть уже через `double`. Для
справочного курса этого достаточно: он показывается как ориентир и ни в
одну денежную операцию не входит — заявка исполняется по курсу, который
назвал менеджер. На границе пакета числа сразу переводятся в десятичную
строку.

Сверх тикета: курс на момент подачи сохраняется в самой заявке
(`preliminary_rate`). Колонка в схеме уже была и пустовала, а менеджеру
в разборе спорной сделки нужно видеть, от чего клиент отталкивался.
Котировка при этом запрашивается до открытия транзакции: держать её
открытой на время запроса к чужому API нельзя.
