# 08 — Отмена заявки

**What to build:** клиент может передумать, пока его заявку никто не взял. Менеджер может отменить заявку на любом шаге, но обязан назвать причину — и клиент эту причину видит.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Клиент отменяет свою заявку, пока она в статусе «новая»
- [ ] Клиент не может отменить заявку, уже взятую в работу
- [ ] Менеджер отменяет заявку из любого незавершённого состояния с обязательным указанием причины
- [ ] Клиент получает уведомление об отмене вместе с причиной
- [ ] Отменённая заявка не допускает дальнейших переходов
- [ ] Отмена записана в историю наравне с остальными переходами
