# 03 — Клиент подаёт заявку на обмен

**What to build:** клиент выбирает, что отдаёт и что получает, указывает сумму и подаёт заявку. Она появляется в системе со статусом «новая», клиент видит подтверждение и свой список заявок. Курс на этом этапе не показывается — экран честно сообщает, что его назовёт менеджер, ровно как ТЗ описывает работу с наличными.

**Blocked by:** 02

**Status:** ready-for-agent

- [x] Экран обмена состоит из двух полей — что отдаю и что получаю — с выбором направления из справочника
- [x] Клиент выбирает способ: электронный перевод или наличные
- [x] Экран явно сообщает, что курс подтвердит менеджер после подачи заявки
- [x] Поданная заявка сохраняется со статусом «новая»; сумма сохраняется без потери точности, включая дробные части криптовалют
- [x] Клиент видит список своих заявок с текущими статусами
- [x] Заявка по неактивному направлению отвергается
- [x] Заявка с нулевой или отрицательной суммой отвергается
