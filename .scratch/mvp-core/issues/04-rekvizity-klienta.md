# 04 — Реквизиты клиента

**What to build:** клиент один раз сохраняет реквизиты для получения денег и при каждой заявке лишь подтверждает их. Сам он видит только последние четыре цифры карты — полный номер в системе хранится зашифрованным и клиентской части недоступен.

**Blocked by:** 03

**Status:** ready-for-agent

- [x] Клиент сохраняет банк, телефон и номер карты; номер уходит в базу зашифрованным
- [x] Клиент видит сохранённую карту в виде последних четырёх цифр
- [x] При подаче заявки клиент подтверждает сохранённые реквизиты или указывает другие
- [x] Клиент может заменить сохранённые реквизиты
- [x] Клиент не может получить реквизиты другого клиента
- [x] Открытый номер карты не появляется ни в базе, ни в логах, ни в ответах клиентского приложения
