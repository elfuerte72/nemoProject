# 04 — Реквизиты клиента

**What to build:** клиент один раз сохраняет реквизиты для получения денег и при каждой заявке лишь подтверждает их. Сам он видит только последние четыре цифры карты — полный номер в системе хранится зашифрованным и клиентской части недоступен.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Клиент сохраняет банк, телефон и номер карты; номер уходит в базу зашифрованным
- [ ] Клиент видит сохранённую карту в виде последних четырёх цифр
- [ ] При подаче заявки клиент подтверждает сохранённые реквизиты или указывает другие
- [ ] Клиент может заменить сохранённые реквизиты
- [ ] Клиент не может получить реквизиты другого клиента
- [ ] Открытый номер карты не появляется ни в базе, ни в логах, ни в ответах клиентского приложения
