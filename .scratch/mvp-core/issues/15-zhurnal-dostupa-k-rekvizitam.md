# 15 — Журнал доступа к реквизитам

**What to build:** каждое обращение менеджера к полному номеру карты клиента оставляет след, и администратор может этот след посмотреть. Восстановить такие сведения задним числом невозможно, поэтому запись должна быть непропускаемой.

**Blocked by:** 04, 07

**Status:** ready-for-agent

- [x] Каждое чтение полного номера карты менеджером записывается в журнал
- [x] Запись содержит сотрудника, время и заявку, в связи с которой был доступ
- [x] Запись в журнал выполняется в одной транзакции с самим чтением: вызывающая сторона не может прочитать номер и не оставить следа
- [x] Администратор видит журнал с отбором по сотруднику, клиенту и периоду
- [x] Журнал доступен только на чтение: правка и удаление записей не предусмотрены
- [x] Менеджер не имеет доступа к журналу

## Comments

Непропускаемость записи обеспечена тем, что расшифрованный номер
возвращается только после вставки строки журнала в той же транзакции:
отдельной операции «записать в журнал», которую можно не позвать, нет.

Чтение доступно менеджеру, который ведёт эту заявку, по тому же правилу
владения, что и остальные действия над ней: у невзятой заявки владельца
нет, взятую читает только взявший.

Реквизиты вывода бонусов сюда не попадают — почему, записано в тикете 12.

### По итогам ревью

Правило доступа ужесточено: реквизиты открываются только менеджеру,
взявшему заявку в работу. Прежнее «у невзятой заявки владельца нет»
описывало механику, а требование ТЗ — «менеджер видит полный номер карты
только в момент работы с его заявкой», и до взятия работы ещё нет.

Журнал принимает обращения обоих родов — к карте клиента и к реквизитам
вывода, — поэтому ссылка на реквизиты стала необязательной, клиент
хранится в записи явно, а проверка требует ровно один предмет.
Соединение с картой при выборке убрано: с ним обращения к реквизитам
вывода выпадали бы из журнала.

Отбор по периоду в админке считает `to` концом дня: `<input type="date">`
даёт полночь, и граница по ней выкидывала бы весь последний день.
Сотрудник выбирается списком — идентификатор наизусть не помнят.
