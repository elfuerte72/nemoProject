# Примитивы панели в пакет `packages/ui`

Status: ready-for-agent
Этап: 2

Из `apps/admin/app/ui/` в `packages/ui` переезжают `stat`, `howto`,
`tabs`, `empty`, `moment`, `copy`, `dialog`, `sidebar`, `topbar`,
иконки и токены оформления из `globals.css` (цвета, поверхности,
кнопки, ряды, пилюли, таблица-список, поля форм, чипы). Панель берёт
их из `@nemo/ui`; в `app/ui/` остаются только её собственные детали:
очередь, карточка клиента, палитра, диалог, живое обновление.
Знак — по-прежнему из `@nemo/brand`.

Вид панели не меняется ни на пиксель: до и после — скриншоты стола,
карточки заявки и настроек на одном сиде, сравнить глазами. Размеры
у кабинета будут те же, что у панели: курсор на ноутбуке, не палец.

Готово, когда `pnpm typecheck`, `pnpm --filter @nemo/admin run test` и
сборка панели зелёные, а `grep` по `apps/admin` не находит импортов из
переехавших файлов. Отдельный PR до кабинета: сломаться здесь может
только сборка, и лучше сломать её одну. `CLAUDE.md`: строка о пакете в
списке пакетов; в `CHANGELOG.md` не пишется — снаружи не видно.
