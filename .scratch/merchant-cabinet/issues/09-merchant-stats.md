# Статистика мерчанта: обзор кабинета и карточка в панели

Status: done
Этап: 6
Blocked by: 02, 05

Операция `summarizeMerchant(actor, merchantId, period)` по правилам
ADR-0013: заявки по дате подачи, деньги по дате исполнения, сравнение с
равным периодом прямо перед выбранным, валюты не складываются.
Числа: заявок подано, исполнено, отменено, в работе; оборот по
валютам отданного; среднее время от подачи до исполнения; вызовов API
за период и доля с ошибкой; доставок вебхуков и доля недоставленных.
Один заход в базу, `cache` на запрос.

Кабинет, **Обзор**: плитки вместо заглушки, чипы периода (7 дней, 30
дней, 90 дней, свой), строка «сегодня» по часам браузера, столбики
подано/исполнено по дням за две недели; CSV заявок за период.

Панель, карточка мерчанта: те же плитки за тот же период и таблица
заявок; в списке мерчантов — исполнено за 30 дней и оборот по валютам.

Тесты: сравнение периодов на сиде с известными числами; валюты не
складываются; заявка клиента не попадает в числа мерчанта.
`CHANGELOG.md`.
