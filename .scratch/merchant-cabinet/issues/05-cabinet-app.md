# Приложение `apps/cabinet`: регистрация, вход, оболочка, заявки на чтение

Status: ready-for-agent
Этап: 2
Blocked by: 01, 03, 04

Третье приложение Next.js в клиентском контуре: переменные как у Mini
App (`DATABASE_URL`, `REQUISITES_PUBLIC_KEY`, без приватного ключа и
без токена бота) плюс `CABINET_URL`, `CABINET_SESSION_SECRET`,
`EMAIL_*`, `API_KEY_PREFIX` (`sk_live_` на боевом, `sk_test_` на
песочнице). Ядро на `globalThis` с прогревом курса в
`instrumentation.ts`, как у Mini App, и с тем же тестом на порядок
запуска. `lib/core.ts`, `lib/api.ts` с `requireSession(request)`:
кука подписана, поколение сверяется с `merchants.session_epoch`,
состояние мерчанта читается на каждом запросе.

Экраны без входа: регистрация (почта, пароль, название, сайт,
контактное лицо, телефон, «что собираетесь делать»), «проверьте
почту», подтверждение адреса по ссылке, вход, «забыли пароль» и сброс
по ссылке из письма. Попытки входа ограничены по почте и адресу;
отказ входа не различает «нет такой почты» и «неверный пароль».

После входа: пока «на рассмотрении» — один экран с этим словом и
ссылкой на поддержку; отклонён — причина и поддержка; активен и
отключён — кабинет (у отключённого без кнопок подачи и с полосой
«доступ отключён»). Оболочка из `@nemo/ui` по устройству Love&Pay:
меню группами, шапка с именем мерчанта и выходом, единая анатомия
раздела. Разделы этого тикета: **Обзор** (приветствие по часам
браузера, последние заявки, ссылки «Документация», «Поддержка»;
плитки — заглушкой «появятся после первых заявок» до тикета 09),
**Заявки** (табы состояний со счётчиками, период, поиск по номеру и
`reference`, «Поля» в куке, «Показать ещё» по курсору, CSV; карточка:
суммы, курс, состояние, лента событий, реквизиты для оплаты и срок,
причина отмены, отмена с подтверждением листом, пока она возможна),
**Настройки** (анкета и профиль, смена пароля с обрывом сессий,
выход), **Поддержка** (ссылка на Telegram). Подсказки «как устроено»
на каждом разделе. Экран перечитывается по таймеру, пока вкладка
видна (`lib/live.ts` панели переиспользуется через `@nemo/ui` или
копируется с тестом).

Тесты: подпись и поколение сессии; отказ отключённому на подачу;
`lib/rate-line` не трогается; вёрстка глазами на тестовом контуре и в
песочнице на `http.server` (память: визуальная проверка). Домены и
DNS — тикет 10. `CHANGELOG.md`: кабинет мерчанта.
