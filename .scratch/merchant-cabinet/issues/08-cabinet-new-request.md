# Заявка руками из кабинета, получатели, курсы

Status: ready-for-agent
Этап: 5
Blocked by: 05

Раздел **Новая заявка** (страница, не модал, как у Love&Pay): два поля
«отдаю / получаю» с живым пересчётом любой стороны (`Money`,
`divideCeil` для обратного счёта), выбор направления из условий
обмена, курс на черте по `lib/rate-line.ts` — вынести из Mini App в
`@nemo/types` или общий пакет с тестом, чтобы правило было одно;
`reference` и комментарий; получатель: из сохранённых или новый прямо
здесь; сводка перед подачей снимком чисел с `quotedAt`; подтверждение.
Только безналичные направления; «в разработке» показываются, но не
подаются, как в Mini App.

Раздел **Получатели**: список сохранённых реквизитов по типам из
`requisiteKindsFor`, добавление формой с проверкой правдоподобия теми
же `looksLike*` и словами `REQUISITE_COMPLAINTS`, чтение QR на
устройстве (`lib/qr.ts` из Mini App — в общий пакет с фикстурами),
архив с подтверждением. Реквизиты, заведённые из тела API, в списке не
показываются (архивированы при подаче).

Раздел **Курсы**: весь справочник направлений живым курсом, сторона
одна на столбец, как в `rates-message.ts`; минимум и срок оплаты;
подсказка о том, что курс заявки фиксируется при подаче на срок
оплаты (ADR-0006).

Тесты: перенос `rate-line` и `qr` без изменения ожиданий; обратный
счёт вверх; вёрстка глазами. `CHANGELOG.md`.
