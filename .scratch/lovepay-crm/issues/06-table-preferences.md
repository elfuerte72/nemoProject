# Личные настройки таблицы стола

Status: resolved
Blocked by: 05

Колонок у стола шесть, на ноутбуке хочется убрать «вид», на телефоне
— оставить три. У Love&Pay это «Поля»: личная настройка в браузере,
коллег не касается.

## Что делать

1. Кнопка «Поля» в действиях страницы открывает лист: какие колонки
   показывать (клиент, вид, ведёт, подана — обмен и состояние
   выключить нельзя), плотность (обычная / плотная), строк на
   странице (25 / 50 / 100 — уходит в `limit` выборки), «Вернуть по
   умолчанию».
2. Хранится в браузере с ключом по сотруднику: два сотрудника на одном
   ноутбуке не видят настроек друг друга.
3. Набор колонок продолжает задаваться одним классом очереди
   (правило `CLAUDE.md`): выключенная колонка убирается из сетки, а не
   прячется.

## Как проверяем

Тестом — чтение/запись настройки: незнакомый ключ даёт значения по
умолчанию, чужой сотрудник не читает чужое, испорченная строка не
роняет страницу. Остальное глазами.

## Answer

Сделано 2 сентября 2026. Настройки — в куке `nemo_desk_table` с идентификатором сотрудника (`apps/admin/lib/table-prefs.ts`, тест рядом): кука, а не `localStorage`, потому что число строк — предел выборки, и знать его должен сервер. Лист «Поля» — `table-prefs-sheet.tsx`; сетка колонок собирается из видимых (`gridColumns`) и уходит переменной в шапку и строки. Маршрут дочитывания принимает тот же предел.
