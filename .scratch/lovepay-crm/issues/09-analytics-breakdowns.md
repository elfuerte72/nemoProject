# Аналитика: разрезы по дням и по менеджерам, выгрузка CSV

Status: ready-for-agent
Blocked by: 08

## Что делать

1. Операция из 08 дополняется разрезом: по дням периода (подано,
   исполнено, оборот по валютам) и по менеджерам (взял, исполнил,
   отменил, конверсия, доход по валютам).
2. Две таблицы под сводкой; у каждой — кнопка «CSV» с разделителем
   `;` и BOM, чтобы открывалось в Excel без настройки кодировки.
3. Выгрузка — маршрутом, отдающим `text/csv` с именем файла по периоду.

## Как проверяем

С падающего теста: разрез по дням не теряет день без заявок (нули),
по менеджерам — заявка, переданная по тикету 07, считается тому, кто
исполнил. CSV — тест сборки строки: точка с запятой внутри значения
экранируется.
