# Палитра ⌘K: переход к заявке и клиенту

Status: resolved
Blocked by: 01

Чтобы открыть заявку по номеру из чата с клиентом, менеджер идёт на
стол, набирает фильтр, ищет строку. У Love&Pay — ⌘K и два символа.

## Что делать

1. Поле в шапке и клавиша ⌘K / Ctrl+K открывают палитру: одно поле,
   подпись «Номер заявки, ник или ID клиента», «введите хотя бы два
   символа».
2. Результаты: открытые заявки по нику/ID клиента — через уже
   существующий фильтр очереди (`query`) двумя запросами (очередь и в
   работе), ограничение десятью строками; полный UUID заявки —
   прямой переход в карточку; число — переход в переписку с клиентом.
3. Стрелки и Enter, Esc закрывает, фокус возвращается в поле шапки.
   Палитра — портал в `body`, как листы в Mini App.

## Как проверяем

Тестом — разбор ввода: UUID распознаётся как заявка, число — как
клиент, остальное — как поиск. Остальное глазами.

## Что не делаем

Поиск по исполненным и отменённым заявкам и по клиентам вне очереди:
операций для этого в ядре нет, они приходят с тикетом 10, и палитра
тогда расширяется.

## Answer

Сделано 2 сентября 2026. Разбор ввода — `apps/admin/lib/palette.ts` (тест рядом): UUID — заявка, число — клиент, остальное — поиск. Маршрут `GET /api/search` ищет теми же операциями, что стол, по пять строк из очереди и из работы. Палитра — `app/ui/palette.tsx`, порталом в `body`; горячая клавиша слушает документ. Поле в шапке стало кнопкой, открывающей палитру. Для проверки глазами заведён `seed-dev.mts` рядом со спекой — только для `nemo_dev`.
