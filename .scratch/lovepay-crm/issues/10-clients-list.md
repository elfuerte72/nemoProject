# Раздел «Клиенты»

Status: ready-for-agent
Blocked by: 01

Клиента видно только врезкой в карточке заявки или переписке. Найти
«того, кто менял баты в июле», нельзя.

## Что делать

1. Операция ядра — список клиентов обеим ролям: поиск по нику и ID,
   курсор, предел; по каждому — в сервисе с, заявок исполнено и
   отменено, последняя заявка, оборот по валютам (сумма отданного по
   исполненным), обращений без ответа. Метка «постоянный» — от трёх
   исполненных.
2. Раздел `/clients` в меню (группа «Основное»): плитки (всего,
   постоянных, с открытой заявкой, без ответа), поиск, табы «Все /
   Постоянные / Ждут ответа», таблица с подвалом пагинации.
3. Карточка клиента `/clients/:id`: врезка `ClientCard` + история
   заявок клиента (операция «заявки клиента для сотрудника» с
   курсором) + ссылка в переписку.
4. Палитра ⌘K (04) расширяется: ищет по клиентам этой операцией.

## Как проверяем

С падающего теста: оборот считается только по исполненным и по
валютам раздельно; «постоянный» — ровно от трёх; поиск по ID точный,
по нику подстрокой; курсор без дублей. Разметка — глазами.
