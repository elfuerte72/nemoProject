# 01 — Настройки экономики переезжают в панель

**What to build:** наценка перестаёт быть свойством направления и становится одним числом в настройках сервиса. Туда же переезжают минимальная сумма обмена и срок жизни неоплаченной заявки — величины, которые сегодня либо не существуют, либо зашиты в коде. Администратор задаёт их в разделе настроек, рядом со ставками линий.

**Status:** ready-for-agent

- [x] Колонка наценки удаляется из справочника направлений; наценка хранится в настройках сервиса одним значением в базисных пунктах
- [x] Предварительный расчёт берёт наценку из настроек, а не из справочника направлений
- [x] В настройках появляются минимальная сумма обмена и срок жизни неоплаченной заявки в минутах
- [x] Заявка на сумму меньше минимальной отвергается отказом операции; на равную минимальной — принимается
- [x] Экран обмена сообщает минимальную сумму до подачи, а не после отказа
- [x] Раздел настроек показывает одно поле наценки вместо списка направлений
- [x] Изменение любой из трёх величин пишется в журнал настроек, как ставки линий
- [x] Значения по умолчанию в миграции: наценка 200 bps, минимальная сумма 3000, срок 120 минут — заглушки, подлежащие замене администратором
- [x] Термин «наценка» в глоссарии перестаёт описываться как задаваемая по валютной паре
