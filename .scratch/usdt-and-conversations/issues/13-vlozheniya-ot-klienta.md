# 13 — Вложения от клиента

**What to build:** клиент присылает скриншот перевода вместо объяснения словами — так работают все обменники. Менеджер видит изображение в панели. При этом чужих номеров карт на дисках сервиса не появляется: хранится ссылка Telegram, а не файл.

**Blocked by:** 11

**Status:** ready-for-agent

- [x] Бот принимает фотографии; сохраняется идентификатор файла Telegram, сам файл не скачивается
- [x] Панель подтягивает изображение по требованию клиентским токеном, который у неё уже есть для уведомлений
- [x] Изображение показывается в диалоговом окне на месте сообщения
- [x] Просмотр вложения пишется в журнал доступа к чувствительным данным — тот же, что ведётся для реквизитов
- [x] Без открытия изображения запись в журнале не появляется
- [x] Недоступное у Telegram вложение показывается как отсутствующее, а не роняет экран
