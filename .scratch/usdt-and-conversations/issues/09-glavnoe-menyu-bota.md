# 09 — Главное меню бота

**What to build:** бот перестаёт быть одной кнопкой под одним абзацем и становится главным меню сервиса. Постоянная клавиатура внизу, кнопка меню чата, список команд, переписанное приветствие. Шаблонный автоответ на любое сообщение исчезает.

**Blocked by:** 03

**Status:** ready-for-agent

- [x] Постоянная клавиатура из четырёх кнопок: открыть обменник, курс, реферальная ссылка, поддержка
- [x] Кнопка меню чата открывает Mini App; список команд бота настраивается при развёртывании
- [x] Приветствие переписывается: что это за сервис, что можно сделать, куда нажимать
- [x] Тексты берутся из заготовок, значения по умолчанию — из кода
- [x] Заглушка «Сообщение получено — им займётся менеджер» удаляется: она обещает то, чего не происходит
- [x] Кнопка поддержки объясняет, что вопрос можно задать здесь же, и что ответит менеджер
- [x] Клавиатура появляется у клиента, уже запускавшего бота ранее, без повторного `/start`
