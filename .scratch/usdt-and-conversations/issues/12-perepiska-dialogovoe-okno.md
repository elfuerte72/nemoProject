# 12 — Переписка: диалоговое окно в панели

**What to build:** менеджер читает разговор, а не расшифровывает список строк. Переписка показывается пузырями с разделением сторон, ответ отправляется оттуда же. Тот же компонент работает предпросмотром при правке заготовок текста: администратор видит, как формулировку прочтёт клиент.

**Blocked by:** 11

**Status:** ready-for-agent

- [x] В панели появляется раздел обращений со списком клиентов, у которых есть переписка
- [x] Переписка показывается диалоговым окном: входящие и исходящие разделены визуально, у исходящих виден автор
- [x] Ответ отправляется из того же окна; кнопка гаснет на пустом тексте
- [x] Из карточки заявки открывается переписка с её клиентом, и в поле ответа уже стоит номер заявки
- [x] Тот же компонент показывает предпросмотр заготовок в настройках
- [x] Менеджер видит, кто из коллег уже ответил, чтобы не писать второе сообщение поверх первого
