# 07 — Курс заявки становится обязательством

**What to build:** курс перестаёт быть справочным. По какому курсу клиент подал заявку — по такому сервис и работает. Правило различается по способу: безналичную заявку определяет курс подачи, наличную по-прежнему котирует менеджер, потому что котировок наличного рынка у сервиса нет.

**Blocked by:** 01

**Status:** ready-for-agent

- [x] Колонка предварительного курса переименовывается в курс заявки: название, которое врёт, хуже отсутствующего
- [x] Безналичная заявка сохраняет курс подачи; подтверждение курса менеджером его не меняет
- [x] Наличная заявка подаётся без курса, и менеджер называет свой при подтверждении
- [x] Безналичная заявка подаётся и тогда, когда источник котировок молчит, — без курса, и дальше ведёт себя как наличная
- [x] Из приложения, уведомлений бота и админ-панели уходит формулировка о предварительности курса
- [x] Экран наличного обмена по-прежнему честно сообщает, что курс назовёт менеджер
- [x] Определение предварительного курса в глоссарии заменяется на курс заявки
- [x] Пишется ADR: решение разворачивает C2 из разбора блокеров, и довод об одностороннем курсовом риске излагается в нём прямо
