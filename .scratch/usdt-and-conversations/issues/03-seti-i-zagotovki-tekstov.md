# 03 — Справочник сетей и заготовки текстов

**What to build:** список сетей перестаёт быть перечислением в коде и становится справочником с признаком активности — администратор гасит сеть, когда кошелёк в ней временно недоступен. Рядом заводится справочник заготовок текста: реквизиты сервиса для оплаты, которые менеджер сегодня набирает руками в каждой заявке, и тексты, которые читает клиент.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Сети хранятся справочником с признаком активности, по образцу справочника валют; заводятся TRC20 и TON
- [ ] Справочник сетей общий для реквизитов обмена и заявок на вывод — двух разных правд о том, куда сервис умеет отправлять, не существует
- [ ] Заявка на вывод в выключенной сети не подаётся
- [ ] Заготовки текста хранятся справочником «ключ — текст»
- [ ] Пустой справочник не ломает работу: значение по умолчанию берётся из кода
- [ ] Администратор включает и выключает сети флажком в настройках
- [ ] Администратор правит заготовки в настройках; правка пишется в журнал настроек
- [ ] Менеджер вставляет реквизиты для оплаты заготовкой из карточки заявки, а не набирает номер руками
